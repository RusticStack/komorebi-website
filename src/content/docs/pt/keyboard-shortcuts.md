---
title: Usar o teclado
lede: As teclas que vai usar mais. F1 no Komorebi mostra todas.
description: Os atalhos de teclado mais usados no Komorebi, para ler, escrever e usar separadores. F1 mostra todas as teclas na aplicação.
---

## Ler

| Tecla | Faz |
|---|---|
| <kbd>Seta para cima</kbd> <kbd>Seta para baixo</kbd> | Mensagem anterior ou seguinte |
| <kbd>Enter</kbd> | Abrir a mensagem |
| <kbd>Ctrl+Q</kbd> <kbd>Ctrl+U</kbd> | Marcar como lida ou não lida |
| <kbd>Backspace</kbd> | Arquivar |
| <kbd>Delete</kbd> | Eliminar |
| <kbd>Ctrl+Shift+V</kbd> | Mover para uma pasta |
| <kbd>Ctrl+Z</kbd> | Desfazer o último arquivo, eliminação, movimento ou envio |
| <kbd>Ctrl+E</kbd> | Pesquisar |
| <kbd>F5</kbd> | Atualizar |

## Escrever

| Tecla | Faz |
|---|---|
| <kbd>Ctrl+N</kbd> | Novo correio |
| <kbd>Ctrl+R</kbd> <kbd>Ctrl+Shift+R</kbd> | Responder, responder a todos |
| <kbd>Ctrl+Shift+F</kbd> | Reencaminhar |
| <kbd>Ctrl+Enter</kbd> | Enviar |
| <kbd>Ctrl+Shift+A</kbd> | Anexar ficheiros |
| <kbd>Ctrl+B</kbd> <kbd>Ctrl+I</kbd> | Negrito, itálico |
| <kbd>Ctrl+K</kbd> | Juntar uma hiperligação |
| <kbd>Esc</kbd> | Fechar e guardar o rascunho |

## Separadores e janelas

| Tecla | Faz |
|---|---|
| <kbd>Shift+Enter</kbd> | Abrir num separador novo |
| <kbd>Ctrl+O</kbd> | Abrir numa janela nova |
| <kbd>Ctrl+W</kbd> | Fechar o separador |
| <kbd>Ctrl+Shift+T</kbd> | Reabrir um separador fechado |
| <kbd>F6</kbd> | Painel seguinte |
| <kbd>Ctrl+,</kbd> | Definições |
