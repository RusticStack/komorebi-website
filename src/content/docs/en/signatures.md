---
title: Use signatures
lede: Named signatures, with a default for new mail and one for replies.
description: Create named signatures in Komorebi, choose a default per account, and switch signatures while you write.
---

1. **Open Settings > Signatures.** Signatures live in one list, each with a name.
2. **Write the signature.** It is formatted text with at most one small logo, a PNG or JPEG up to 200 KB.
3. **Choose the defaults.** Each account has one default for new messages and one for replies and forwards. Either can be None.
4. **Change it while you write.** The composer's **Signature** menu swaps it; <kbd>Ctrl+Z</kbd> puts the old one back.

The signature goes under your text and above any quoted text. Choosing another From account swaps in that account's default while you have not changed it.
