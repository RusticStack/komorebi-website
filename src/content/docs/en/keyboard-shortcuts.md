---

## Reading

| Key | Does |
|---|---|
| <kbd>Up</kbd> <kbd>Down</kbd> | Previous or next message |
| <kbd>Enter</kbd> | Open the message |
| <kbd>Ctrl+Q</kbd> <kbd>Ctrl+U</kbd> | Mark as read or unread |
| <kbd>Backspace</kbd> | Archive |
| <kbd>Delete</kbd> | Delete |
| <kbd>Ctrl+Shift+V</kbd> | Move to a folder |
| <kbd>Ctrl+Z</kbd> | Undo the last archive, delete, move or send |
| <kbd>Ctrl+S</kbd> | Save the message as a .eml file |
| <kbd>Ctrl+E</kbd> <kbd>F3</kbd> <kbd>Ctrl+F</kbd> | Search |
| <kbd>Ctrl+Shift+I</kbd> | Go to the Inbox |
| <kbd>F5</kbd> | Refresh |

## Writing

| Key | Does |
|---|---|
| <kbd>Ctrl+N</kbd> | New mail |
| <kbd>Ctrl+R</kbd> <kbd>Ctrl+Shift+R</kbd> | Reply, reply all |
| <kbd>Ctrl+Shift+F</kbd> | Forward |
| <kbd>Ctrl+Enter</kbd> | Send |
| <kbd>Ctrl+Shift+A</kbd> | Attach files |
| <kbd>Ctrl+B</kbd> <kbd>Ctrl+I</kbd> | Bold, italic |
| <kbd>Ctrl+K</kbd> | Add a link |
| <kbd>Esc</kbd> | Close and keep the draft |

## Tabs and windows

| Key | Does |
|---|---|
| <kbd>Shift+Enter</kbd> | Open in a new tab |
| <kbd>Ctrl+O</kbd> | Open in a new window |
| <kbd>Ctrl+W</kbd> | Close the tab |
| <kbd>Ctrl+Shift+T</kbd> | Reopen a closed tab |
| <kbd>F6</kbd> | Next pane |
| <kbd>Ctrl+Shift+E</kbd> | Show or hide the folders |
| <kbd>Ctrl+,</kbd> | Settings |

## Access keys

Hold <kbd>Alt</kbd> to see a letter under each main command, then press <kbd>Alt</kbd> and that letter to run it. The letters follow the language, so they differ in Portuguese. In English, <kbd>Alt+N</kbd> is New mail and <kbd>Alt+R</kbd> is Reply.
