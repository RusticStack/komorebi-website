eM Client is a full-featured commercial mail app with a free tier. Komorebi is free and open source, with fewer features and no limits on accounts.

## At a glance

<Compare>

| | Komorebi | eM Client |
|---|---|---|
| Price | Free | Free tier; paid Personal and Business plans |
| Free tier limits | None | 2 accounts, home use on 1 device |
| Source code | Open (GPL-3.0-or-later) | Closed |
| Systems | Windows 10 and 11 | Windows and macOS, plus mobile apps |
| Account types | IMAP and SMTP | IMAP, POP3, Exchange, Gmail, Microsoft and more |
| Calendar and contacts | Yes, CalDAV and CardDAV | Yes |
| PGP | No | Yes |
| AI features | None | An AI add-on in paid plans |
| Telemetry | None | See eM Client's privacy policy |

</Compare>

## When Komorebi fits

- You have more than two accounts and want to pay nothing.
- You want open source code you can build yourself.
- IMAP and SMTP with a password cover your accounts.

## When eM Client fits better

- You need Exchange, PGP or OAuth sign-in.
- You want macOS as well as Windows.
- You want a large feature set in one app.
