The new Outlook for Windows is Microsoft's mail app. Komorebi is a small, independent IMAP client. They suit different people. Here is how they differ.

## At a glance

<Compare>

| | Komorebi | New Outlook for Windows |
|---|---|---|
| Price | Free | Free with Windows; some features need Microsoft 365 |
| Source code | Open (GPL-3.0-or-later) | Closed |
| Systems | Windows 10 and 11 | Windows, also on web, Mac and mobile |
| Account types | IMAP and SMTP | Microsoft accounts, Exchange, Gmail, Yahoo, IMAP |
| Sign-in | Password or app password | Includes OAuth (Microsoft, Google) |
| Where synced mail lives | On your PC and your mail server | Microsoft documents a copy in its cloud for some non-Microsoft accounts |
| Telemetry | None | Microsoft collects diagnostic data |
| AI assistant | None | Copilot, with a Microsoft 365 plan |

</Compare>

## When Komorebi fits

- You use an IMAP provider such as Purelymail, Postale.io or your own server.
- You want mail to stay between your PC and your mail server.
- You want a small native app with no account to create.

## When Outlook fits better

- You use Exchange, Microsoft 365 or Outlook.com. Komorebi cannot sign in to accounts that require OAuth.
- You need mail on several devices from one app.
- You rely on Microsoft 365 features such as shared calendars.
