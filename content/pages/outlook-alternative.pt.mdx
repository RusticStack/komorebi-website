O novo Outlook para Windows é a aplicação de correio da Microsoft. O Komorebi é um cliente IMAP pequeno e independente. Servem pessoas diferentes. Eis como diferem.

## Num relance

<Compare>

| | Komorebi | Novo Outlook para Windows |
|---|---|---|
| Preço | Gratuito | Gratuito com o Windows; algumas funcionalidades exigem Microsoft 365 |
| Código-fonte | Aberto (GPL-3.0-or-later) | Fechado |
| Sistemas | Windows 10 e 11 | Windows, e também web, Mac e telemóvel |
| Tipos de conta | IMAP e SMTP | Contas Microsoft, Exchange, Gmail, Yahoo, IMAP |
| Início de sessão | Palavra-passe ou palavra-passe de aplicação | Inclui OAuth (Microsoft, Google) |
| Onde fica o correio sincronizado | No seu PC e no seu servidor de correio | A Microsoft documenta uma cópia na sua nuvem para algumas contas não Microsoft |
| Telemetria | Nenhuma | A Microsoft recolhe dados de diagnóstico |
| Assistente de IA | Nenhum | Copilot, com um plano Microsoft 365 |

</Compare>

## Quando o Komorebi serve

- Usa um fornecedor IMAP como a Purelymail, a Postale.io ou o seu servidor.
- Quer que o correio fique entre o seu PC e o seu servidor de correio.
- Quer uma aplicação nativa pequena, sem conta para criar.

## Quando o Outlook serve melhor

- Usa Exchange, Microsoft 365 ou Outlook.com. O Komorebi não inicia sessão em contas que exigem OAuth.
- Precisa do correio em vários dispositivos na mesma aplicação.
- Depende de funcionalidades do Microsoft 365, como calendários partilhados.

## Mudar do Outlook

<Steps>
<Step title="Confirme que o fornecedor oferece IMAP">

O Komorebi precisa de IMAP e SMTP com palavra-passe ou palavra-passe de aplicação.

</Step>
<Step title="Instale o Komorebi">

[Instalar o Komorebi](/pt/docs/getting-started), só para o seu utilizador.

</Step>
<Step title="Adicione a conta">

O correio fica no servidor, por isso é transferido de novo. [Adicionar uma conta](/pt/docs/adding-an-account).

</Step>
</Steps>
