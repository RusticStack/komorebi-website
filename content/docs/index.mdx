Komorebi is a small, fast email client for Windows 10 and 11. It is free and open source (GPL-3.0-or-later), written in Rust with Slint, and keeps a local SQLite cache of your IMAP mail. It has no AI, no telemetry and no web engine: HTML mail is drawn by its own layout engine.

- [Adding an account](/docs/adding-an-account): Purelymail, Postale.io and any other IMAP and SMTP server.
