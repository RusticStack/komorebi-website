Komorebi is Rust with [Slint](https://slint.dev) (Fluent style, software renderer).

## What you need

- Windows 10 or 11, x64.
- [Rust](https://rustup.rs). rustup picks the toolchain from `rust-toolchain.toml`.
- Visual Studio Build Tools with **Desktop development with C++**.

## Build and run

```powershell
git clone https://github.com/RusticStack/komorebi
cd komorebi
cargo build --release --locked
.\target\release\komorebi.exe
```

`komorebi.exe` is one file. Copy it anywhere. Its data lives in `%LOCALAPPDATA%\komorebi`.

## Run the checks

The same checks CI runs:

```powershell
cargo fmt --check
cargo clippy --all-targets --locked -- -D warnings
cargo test --locked
pwsh scripts/check-pins.ps1
cargo deny --locked check licenses advisories
```

<Advanced title="A boot check without your mail">

Komorebi can render its window to a file and exit, on a throwaway cache with made-up messages, offline and without your passwords:

```powershell
cargo run --release --locked --example seed -- $env:TEMP\seed.sqlite3 2000
$env:KOMOREBI_OFFLINE = 1; $env:KOMOREBI_DB = "$env:TEMP\seed.sqlite3"
$env:KOMOREBI_SNAPSHOT = "$env:TEMP\boot.bmp"; $env:KOMOREBI_SNAPSHOT_SELECT = 0
$env:KOMOREBI_SNAPSHOT_CHECK = 1; $env:KOMOREBI_TIMING = 1
(Start-Process target\release\komorebi.exe -NoNewWindow -Wait -PassThru).ExitCode
```

Exit code 0 means the list and reader are not blank. `KOMOREBI_TIMING` prints launch timings. The screenshots on this site were made this way. A release build must stay at most 20,500,000 bytes.

</Advanced>
