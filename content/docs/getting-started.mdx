## What you need

- Windows 10 or 11, 64-bit (x64).
- A mail account with IMAP and SMTP and a password or app password.

<Callout title="No OAuth sign-in">
Accounts that only allow OAuth, such as Microsoft 365 and Outlook.com, do not work.
</Callout>

## Download

Download <DownloadLink /> from the [download page](/download). Two small files sit next to it on GitHub: `.sha256` (its hash) and `.sig` (for in-app updates).

## Check the download [#check-the-download]

The installer is not code-signed yet, so check its hash first. In PowerShell, in your downloads folder:

```powershell
(Get-FileHash .\komorebi-0.7.0-setup.exe -Algorithm SHA256).Hash.ToLower()
Get-Content .\komorebi-0.7.0-setup.exe.sha256
```

Both lines must match. If not, delete the file and download it again.

## Install

<Steps>
<Step title="Run the installer">

It installs for your user only, into `%LOCALAPPDATA%\Programs\Komorebi`. No admin rights.

</Step>
<Step title="Pass SmartScreen">

If Windows says "Windows protected your PC", choose **More info**, then **Run anyway**.

</Step>
<Step title="Pick your options">

A desktop shortcut and starting with Windows are optional.

</Step>
</Steps>

<Advanced title="Install for all users, or silently">

- The first page offers an install for all users, into `Program Files\Komorebi`. It asks for admin rights. `/ALLUSERS` does the same.
- `/SILENT` or `/VERYSILENT` install without questions.
- The installer registers Komorebi as a mail app. Pick it for email links in Settings > Apps > Default apps.

</Advanced>

## First start

A welcome screen asks you to add your email account. It has a **Language** box that switches at once.

<Shot name="welcome" alt="The first start on a new install: the welcome screen" />

Komorebi follows the Windows display language. Portuguese (except Brazilian) shows in European Portuguese; everything else in English.
