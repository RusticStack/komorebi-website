All of these are off until you turn them on in Settings > General.

<Shot name="settings-general" alt="Settings, General: theme, language and reading options" />

| Setting | Does |
|---|---|
| **Notifications for new mail** | A Windows notification when mail arrives |
| **Show the sender and subject in notifications** | Otherwise it says only "New mail" |
| **Notifications for event reminders** | A notification when a reminder is due |
| **Keep running in the notification area when the window closes** | Mail keeps arriving after you close the window |
| **Start with Windows** | Starts Komorebi in the notification area when you sign in |

Each account's page has **Notifications for this account** to leave an account out.

## What does not notify

- A new account's first download.
- Mail a [rule](/docs/rules) files away or marks read.

<Callout title="Lock screen">
Windows may show notifications on the lock screen. To keep sender and subject private, turn off **Show the sender and subject in notifications**.
</Callout>

<Advanced title="How it works">

- Notifications come from the sync connection Komorebi already has. No push service, no cloud relay.
- Reminders run on one timer in the app, so they show only while Komorebi runs. One missed by more than five minutes stays a marker in the agenda.
- **Pause notifications** in the tray icon's menu pauses both kinds. Quit from that menu too.
- Start with Windows writes one value, `Komorebi`, under `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, with `--minimized`. Turning it off removes it.
- An optional taskbar flash marks new mail while the window is in the background.

</Advanced>
