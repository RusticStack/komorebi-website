O Komorebi é escrito em Rust com [Slint](https://slint.dev) (estilo Fluent, renderização por software).

## O que precisa

- Windows 10 ou 11, x64.
- [Rust](https://rustup.rs). O rustup escolhe a toolchain de `rust-toolchain.toml`.
- Visual Studio Build Tools com **Desenvolvimento de ambiente de trabalho com C++**.

## Compilar e executar

```powershell
git clone https://github.com/RusticStack/komorebi
cd komorebi
cargo build --release --locked
.\target\release\komorebi.exe
```

O `komorebi.exe` é um único ficheiro. Copie-o para onde quiser. Os dados ficam em `%LOCALAPPDATA%\komorebi`.

## Correr as verificações

As mesmas verificações que a CI corre:

```powershell
cargo fmt --check
cargo clippy --all-targets --locked -- -D warnings
cargo test --locked
pwsh scripts/check-pins.ps1
cargo deny --locked check licenses advisories
```

<Advanced title="Uma verificação de arranque sem o seu correio">

O Komorebi pode desenhar a janela para um ficheiro e sair, numa cache descartável com mensagens fictícias, sem rede e sem as suas palavras-passe:

```powershell
cargo run --release --locked --example seed -- $env:TEMP\seed.sqlite3 2000
$env:KOMOREBI_OFFLINE = 1; $env:KOMOREBI_DB = "$env:TEMP\seed.sqlite3"
$env:KOMOREBI_SNAPSHOT = "$env:TEMP\boot.bmp"; $env:KOMOREBI_SNAPSHOT_SELECT = 0
$env:KOMOREBI_SNAPSHOT_CHECK = 1; $env:KOMOREBI_TIMING = 1
(Start-Process target\release\komorebi.exe -NoNewWindow -Wait -PassThru).ExitCode
```

O código de saída 0 significa que a lista e o leitor não estão vazios. `KOMOREBI_TIMING` mostra os tempos de arranque. As imagens deste site foram feitas assim. Uma compilação de versão tem de ficar com no máximo 20 500 000 bytes.

</Advanced>
