---
title: Signatures
description: Create named signatures with formatting and a small logo, and set a default per account for new mail and replies.
---

Signatures live in one list in Settings > **Signatures**. Each has a name, formatted text and at most one small logo (PNG or JPEG, up to 200 KB).

<Shot name="compose-signature" alt="A new message with the account's default named signature" />

## Set a default

Each account has two defaults:

| Default | Used for |
|---|---|
| New messages | New mail |
| Replies and forwards | Reply, Reply all, Forward |

Either can be **None**. The signature goes under your text, above any quoted text.

## Change it in a message

The composer's **Signature** menu swaps it. <Kbd>Ctrl+Z</Kbd> puts the old one back. A different **From** account swaps it too, until you edit it.
