## E-mail HTML

O Komorebi desenha o e-mail HTML com o seu próprio motor de renderização. Não tem motor de scripts nem código de rede.

- Os scripts nunca correm.
- Folhas de estilo, tipos de letra e píxeis de rastreio remotos nunca são transferidos.

## Imagens remotas

As imagens remotas ficam bloqueadas até decidir. Uma barra por cima da mensagem conta-as e avisa: transferi-las diz ao remetente quando abriu a mensagem, e o seu endereço IP.

| Botão | Faz |
|---|---|
| **Transferir imagens** | Transfere-as para esta mensagem |
| **Transferir sempre deste remetente** | Junta esse endereço exato a uma lista |

Reveja a lista em Definições > Privacidade.

## Hiperligações

Uma hiperligação só abre no browser depois de uma pergunta que mostra o endereço completo.

## Anexos

- Os anexos nunca abrem sozinhos.
- Programas e scripts só podem ser guardados.
- Os ficheiros guardados recebem a Marca da Web do Windows, para que o SmartScreen e o Office os tratem com cuidado.
